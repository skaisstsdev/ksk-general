# KSK Farmos — конвенции проекта

Стартовый документ: `BRIEF.md`. Материалы старого сайта: `_source/` (только чтение, не собирается).
Работа идёт поэтапно по разделу 7 брифа — после каждого этапа остановка и подтверждение.

## Правила, нарушение которых воспроизводит проблемы старого сайта

- **Смена подложки не разделяет блоки.** Страница живёт на одном поле; границу
  задают пауза (`pause="beat|break|turn"`), смена выключки и масштаб. Линейка —
  инструмент внутри блока, не между блоками.
- **Сетка — только через `Grid`/`Col`.** Двенадцать колонок и один промежуток
  на весь сайт. Разрешённых мест четыре: `full · text · wide · aside`.
  Раньше сетка собиралась в каждой секции руками, промежуток гулял между
  32 и 48 пикселями, и правая колонка начиналась то на 917, то на 927,
  то на 706, то на 744, то на 793 — пять вертикалей на одной странице.
  Теперь их ровно две: 194 и 826 при ширине 1440.
- **Хиро — важнейшая часть сайта.** Делается скрупулёзно, с отдельным запасом
  итераций, и проверяется на 1440 и на 375 по отдельности.
- **Никаких литеральных цветов и размеров в компонентах.** Всё берётся из токенов
  в `src/app/globals.css` (`@theme`). Ступени названы по роли:
  шрифт — `eyebrow · caption · meta · ui · body · lead · subhead · h4 · h3 · h2 · h1`,
  отступы — `3xs…4xl` плюс паузы `beat · break · turn`.
  Проверяется `npm run check:scale` — он же ловит подложку-разделитель,
  цвет мимо палитры и запрещённый брейкпоинт `md`.
- **Никакого `!important`.** В старом `style.css` их 609 на 2387 строк — именно поэтому
  любая правка ломала вёрстку.
- **Анимации — только Motion** (`motion/react`), никаких ручных замеров высоты
  и `setTimeout`, синхронизированных с CSS-переходами.
- **Header и footer — компоненты.** В старом сайте они были скопированы в десять файлов.
- **Реквизиты — только из `src/content/site.ts`.** Ни одного телефона или адреса в разметке.
- **Только self-hosted.** Никаких внешних CDN: в старом сайте это было нарушением DSGVO.
- **Ссылки — из `@/i18n/navigation`**, не из `next/link`: языковой префикс подставляется сам.

## Грамматики

Три системы правил заданы **только переопределением токенов** — `[data-grammar="a|b|c"]`
в `globals.css`. Компоненты у всех трёх одни и те же. Если грамматику нельзя выразить
токенами, значит она держится на ручной вёрстке и не переживёт второй проект.
Сравнение — `/entwurf`.

## Структура

```
src/app/[locale]/     маршруты; корневой layout внутри сегмента языка
src/components/ui/    базовые компоненты дизайн-системы
src/components/layout/ шапка, футер, меню, переключатель языков
src/content/          контент и реквизиты, отделённые от разметки
src/i18n/             routing / navigation / request для next-intl
src/proxy.ts          в Next 16 это бывший middleware
```

## Next.js 16

`middleware` переименован в `proxy`, `params` и `searchParams` только асинхронные.
Перед правкой незнакомого API — читать `node_modules/next/dist/docs/`.
